## 대체 공공 행사: 실제 수집과 보류 근거

[서울시 문화행사 데이터셋](https://data.seoul.go.kr/dataList/OA-15486/A/1/datasetView.do)은11/13 갱신, 공공누리1유형 출처표시, 서울특별시 저작권·제3저작권자 없음으로 표시됐다. 기존 SeoulEvents를 sample로1회만 호출해 HTTP200/INFO-000, 전체 보고19,761 중 첫5건을 수신·정규화했다. 전수 수집/팝업 전용 검색이 아니다. 데이터 수신 시점은13:47 KST다. 포스터·예매처 글/사진/음원의 권리를 이 데이터셋 허가로 확대하지 않는다.

이 다섯 항목을 행사의 전체 운영정보가 검증된 것으로 승인하지 않는다. API는 좌표·날짜를 제공하지만 수동 주최사 확인·취소 상태·자동차 이동시간을 보증하지 않는다. 별도 검증용 DB에만 저장했다. 기존 원본 DB는 변경하지 않았다. 상세200/tts_eligible=false, feed/음성 큐 미포함과 DRIVING_TIME_UNVERIFIED를 실제 HTTP로 확인했다. **5건 모두 LIVE 추천0/음성0**이다. 새로 만든 합성 행사를 실제 수집으로 세지 않았다.

지브리 공연을 한 건 더 대조한 결과:

- 공식 API의 행사일은12/22이고, 좌표는37.5260087284496,126.900109255921이다. 이는 실제 API 좌표이며 자동차 출입구/경로 도착점의 검증은 아니다.
- [영등포문화재단 장소 안내](https://www.ydpcf.or.kr/arthall/arthall.do)에서 영등포아트홀 주소 **서울시 영등포구 국회대로596**을 확인했다. 다른 행사장이나 팝업 좌표로 전용하지 않았다.
- [공식 티켓 판매처 공지](https://www.ticketlink.co.kr/help/notice/66259)는 주최/주관 지누락엔터테인먼트를 명시한다. 그러나 같은 공지의 공연정보에는17시, 투어 일정에는19:30으로 서로 다른 시간이 있다. **SCHEDULE_TIME_CONFLICT로 보류**하고 한쪽을 임의 선택하지 않았다.
- 서울문화포털 상세 원문은 직접 열기에서 timeout이 발생했다. 검색에 노출된 예전 포스터/요약을 새 실시간 원문 확인으로 기록하지 않았다.
- 공지에서 취소 문구를 못 찾은 것과 취소가 없다는 보증은 다르다. 예약·차량 길안내 대상으로 확정하기 전에 주최/최종 공지를 재확인해야 한다.

## 날씨·호출량·안전 경계
