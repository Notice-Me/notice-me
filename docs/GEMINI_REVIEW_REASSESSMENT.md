## 11/15 MVP 안정화

- 서버 담당: 현재 계약·권리/만료/날씨 전용 음성·미검증 행사 제외·MOCK 회귀 유지. 시연 직전 실제 관측시각/만료와 서버 주소·응답을 확인한다. 자동화 구축을 이유로 외부 콘텐츠 재수집/AI 전송 범위를 넓히지 않는다.
- 앱 담당: 팀원 UI/UX를 보존하고 서버 모델·재생/패스/다시/중단·연결 실패·날씨 만료를 정차 시연에서 확인한다. 주행 적합성/차량 안전이 검증됐다는 표현을 사용하지 않는다. 이번 작업자가 앱을 수정/설치/실행한 것은 아니다.
- 공동: 기존 제한을 시연 설명에 명시하고 버전·서버 모드·데이터 시각·검증한 경로를 기록한다. 모든 미완료 기능을 마감 전에 한 번에 추가하는 계획을 피한다.

## 본선2차 개발

1. [프로필 OR/검색 AND](INTEREST_PROFILE_PROPOSAL.md) 계약 합의 후 서버/API·앱 입력 분리 구현과 회귀 시험.
2. [공식 팝업](CONTENT_SOURCE_FOLLOWUP.md)의 주소/좌표/개별 운영사·변경/취소·권리 검증과 취소 격리 절차.
3. [실제 RoutingProvider](ROUTING_TRIAL_PROPOSAL.md), 무료 계정/키·조건·호출 예산 확인 뒤 소량 실제 시험.
4. 차량 플랫폼 UX 제한·오디오 포커스·실차/경쟁 오디오·목적지 생성·음성 명령은 앱 담당의 공식 권한과 실제 시험으로 검증.
5. 멀티 AI 자동 연결은 파일 절차와 실제 모델/계정/예산·전송 승인부터 확인. 코드 리뷰 제안은 테스트 없이 자동 적용하지 않는다.

원문 파일이 도착하면 전체를 읽고 문장/항목별 근거와 위 판단을 대조한다. 새 사실이 확인되면 이전 관측을 이력으로 남기고 이 문서를 갱신한다.
