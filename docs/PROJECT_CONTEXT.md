# Notice Me — Project context

기준: 2026-11-11 사용자 개발 지시. 목표: 2026-11-15까지 실제 수집 → 추천 → FastAPI JSON 핵심 프로토타입. 서버 담당 1명, Pleos 차량 앱 담당 1명. 기존 신청서의 개인 연락정보는 저장소에 옮기지 않습니다.

## 제품과 운영 규칙

현재 위치, 내비게이션 경로, 목적지, 관심사를 결합한 차량 인포테인먼트입니다. 네 콘텐츠 영역(지역 뉴스/행사/전시/생활정보)을 동일한 후보 풀로 평가합니다. 관심사 뉴스는 지역과 관계없이 추천할 수 있습니다. 지역 뉴스는 현재 위치·경로·목적지 관련성이 필요합니다. 생활정보는 등록 관심사 일치가 필수입니다.

행사/전시는 공식 개최 확인, 유효 일정, 장소 확인과 자동차 이동시간 60분 이내 검증이 필요합니다. 직선거리나 임의 속도를 실제 이동시간으로 표시하지 않습니다. 검증된 라우팅이 없으면 추천에서 제외하고 미검증 상태를 드러냅니다. 캐릭터 팝업은 공공 API에 없을 수 있으므로 별도 발견/검증 모듈을 둡니다. 첫 버전은 공식 URL·확인일·개최 확정·유효기간이 있는 수동 등록과 자동 공공 수집을 출처 구분하여 사용합니다.

사고/도로 통제는 실제 경로 관련성, 발생 시각, 위치, 영향 범위, 상태, 공식 출처, 정보 유효성을 확인한 경우 최우선입니다. 시뮬레이션은 SIMULATED로 표시하고 실시간 정보로 주장하지 않습니다. 경로 링크/좌표 확장 구조를 준비합니다.

화면에는 추천 점수 상위 최대 3건. 음성 큐는 별도 생성하며 3건 제한이 없습니다. 권리가 확인된 콘텐츠만 큐에 넣습니다. 긴급정보는 alerts로 별도 제공하고 일반 큐보다 먼저 처리합니다. 내비 사용 시 목적지와 남은 ETA에 맞추어 대기 큐를 재평가하며 도착 전 여유시간을 둡니다. 내비 미사용 시 현재 위치 중심입니다. 재생 시작, 중단, 다음/다시, 오디오 포커스는 차량 앱에서 제어합니다. 위치 진입만으로 자동 낭독하지 않습니다.

## 권리와 AI

뉴스 제공 API 접근권과 언론사 AI 요약/TTS 재배포권은 별개입니다. TTS_ALLOWED / LINK_ONLY / LICENSE_UNVERIFIED를 기록하고 마지막 두 상태는 음성 및 LLM 처리에서 차단합니다. 출처를 항상 보존합니다. 자료에 없는 사실은 생성하지 않습니다.

학교 AI 토큰은 추후 연결합니다. 엔드포인트를 가정하지 않고 LLMProvider 인터페이스(분류, 권리 확보 자료 요약, 상세 설명)와 deterministic mock을 제공합니다. MOCK 응답을 실제 AI 응답으로 표시하지 않습니다.

## 기술 및 분업

Python >=3.11, FastAPI, SQLite, httpx, pytest, 로컬 .env. 서버: 수집기, 정규화, 중복 제거, 저장, 규칙 기반 점수/근거, 유효기간, 권리 게이트, REST API. 차량 앱: 관심사 설정, 위치/내비/ETA 제공, 화면, TTS, 미디어 제어, SDK/주행 UX 검증. 경로·위치 이력은 기본 저장하지 않습니다.

서버 API: health, feed, contents/{id}, contents/{id}/explain. 정확한 필드와 변경 이력은 API_CONTRACT.md. 공식 출처와 호출 결과는 DATA_SOURCES.md. 완료/미완료는 PROJECT_STATUS.md.

## 2026-11-11 재검증 이후 MVP 실행 순서

핵심 서버를 재작성하지 않고 유효성 오류 수정과 응답 타입/연결 도구를 보강했습니다. 즉시 다음 단계는 Pleos 에뮬레이터·실차의 앱 HTTP 호출→카드/큐→허용 brief TTS 검증입니다. FreeNews 인증/일부 실제 수신은 확인했지만 뉴스 가공·재배포 라이선스, 실제 라우팅/차량 링크 매핑, 학교 AI는 미완료입니다. 최소 시연에서는 확인된 공공자료 경로와 명시적으로 표시된 Mock을 사용할 수 있으나 원래 전체 기획을 실자료로 구현했다는 의미는 아닙니다. 최신 우선순위/완료 기준은 [PROJECT_STATUS](PROJECT_STATUS.md), 팀원 실행은 [VEHICLE_INTEGRATION](VEHICLE_INTEGRATION.md), 실제 결과 기록은 [VEHICLE_ACCEPTANCE](VEHICLE_ACCEPTANCE.md)를 따릅니다.
